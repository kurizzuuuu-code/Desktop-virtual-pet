How she notices games

Three ways, simplest first: window titles (automatic) → running processes → screen reading / log files (most setup). You only need one.

React to what you're doing

Uses a Windows focus hook (like native desktop pets) — only checks the active app when you switch windows, not on a timer. Cooldown between speech reactions.

Built into the app (Windows API) — no admin, no extra permissions. Click Test, then within 3 seconds focus YouTube or your game.

Detect games without log files

Most online games are already recognized by window title — no setup. For fullscreen games with blank titles, detect the running game process instead. Screen OCR (experimental) reads defeat text like YOU DIED straight off the screen while a game is active.

Screen watch is OFF
