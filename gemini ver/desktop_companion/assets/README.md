# Custom Animation Guide

To give your pet custom animations, simply drop your own **GIFs**, **PNGs**, or **frame sequences** into the corresponding folders below:

- `assets/custom_animations/idle/` — The default resting animation.
- `assets/custom_animations/walk/` — Used when the pet roams or walks across the screen.
- `assets/custom_animations/talk/` — Used when speaking dialogue.
- `assets/custom_animations/dance/` — Used when background music/beats are detected.
- `assets/custom_animations/cheer/` — Used when cheering you on during gaming.
- `assets/custom_animations/tease/` — Used when playfully teasing you during gaming.

### Supported Asset Formats:
- Animated GIF (`.gif`)
- Static Images or Image Sequences (`.png`, `.jpg`, `.webp`)
- Transparent backgrounds are recommended.
